# linux-projeto

Projeto desenvolvido durante o bootcamp Linux Experience da DIO.

## Sobre

Este repositório contém scripts e arquivos relacionados ao aprendizado de Linux, desenvolvidos como parte das atividades do bootcamp Linux Experience promovido pela Digital Innovation One (DIO).

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/all3x-martins/linux-projeto.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd linux-projeto
   ```
3. Execute os scripts conforme a necessidade:
   ```bash
   ./nome-do-script.sh
   ```

> Certifique-se de dar permissões de execução aos scripts, se necessário:
> ```bash
> chmod +x nome-do-script.sh
> ```
