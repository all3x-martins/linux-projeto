# Linux Projeto

Repositório desenvolvido durante o **Bootcamp Linux Experience** da Digital Innovation One (DIO).

## Sobre o projeto

Este repositório reúne scripts criados como parte das atividades práticas do bootcamp, com foco em fundamentos de administração de sistemas Linux e conceitos introdutórios de automação e infraestrutura como código.

O objetivo é demonstrar a aplicação prática de comandos e rotinas administrativas em shell script, consolidando conhecimentos adquiridos durante o curso.

## Objetivos de aprendizado

- Criar e gerenciar usuários em sistemas Linux por meio de scripts.
- Automatizar tarefas administrativas utilizando shell script.
- Aplicar conceitos básicos de Infraestrutura como Código (IaC).
- Consolidar boas práticas no uso de permissões e execução de scripts.

## Estrutura do repositório

- **criar-usuarios.sh** → Script para criação automatizada de usuários.
- **iac-v1.sh** → Primeira versão de script voltado a práticas de Infraestrutura como Código.
- **script-iac-v2.sh** → Versão revisada e aprimorada do script de IaC.
- **README.md** → Documento explicativo do projeto.

## Como utilizar

1. Clone o repositório:
   ```bash
   git clone https://github.com/all3x-martins/linux-projeto.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd linux-projeto
   ```

3. Dê permissão de execução ao script desejado:
   ```bash
   chmod +x nome-do-script.sh
   ```

4. Execute o script:
   ```bash
   ./nome-do-script.sh
   ```
